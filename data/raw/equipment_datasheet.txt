# Injection-Molding Machine Technical Datasheet

Document ID: FIQ-DS-001
Revision: 1.0
Document Type: Equipment Technical Datasheet
Status: Fictional document for ForgeIQ development and testing

## 1. Purpose and Scope

This datasheet describes a fictional injection-molding machine configuration used to test document retrieval, specification lookup, and source attribution in ForgeIQ.

All equipment identifiers, component details, and numerical values in this document are synthetic examples. They do not describe a real machine and must not be used for equipment selection, commissioning, operation, maintenance, or safety decisions.

## 2. Equipment Identification

Equipment identifier: FIQ-IMM-001

Equipment description: Fictional injection-molding machine

Equipment category: Manufacturing equipment

Primary subsystems:

* Injection unit
* Clamping unit
* Hydraulic drive system
* Temperature control system
* Machine control system

Intended demonstration use: Testing an industrial maintenance knowledge assistant.

The fictional machine contains the following example components.

## 5. Specification Interpretation

A value appearing in this datasheet describes only the fictional configuration defined in this document.

The presence of a numerical value does not establish that the value is suitable for another machine or configuration.

ForgeIQ should preserve the distinction between:

* A value explicitly stated in the source document.
* A value calculated from documented information.
* A value that is missing from the available documentation.
* An illustrative value created for software testing.

If a requested specification is absent, the assistant must state that the available documentation does not specify it rather than inventing a value.
